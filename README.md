# Ad Performance Copilot

**The Monday paid-media review, done before the stand-up.**

Export last month's results from Meta Ads, Google Ads and LinkedIn Ads into one CSV. The copilot calculates the numbers that matter, spots the problems a busy media buyer misses, and proposes how to move budget next week. Optionally, Claude writes the client summary.

```
$ adcopilot data/ads_export.csv --target-cpa 40 --target-roas 1.5

| Spend       | Revenue     | ROAS  | Conversions | CPA       |
| EUR 23,163  | EUR 53,611  | 2.31x | 850         | EUR 27.25 |

What needs attention
- Act · Prospecting · DACH · UGC video. Creative fatigue: CTR 1.36% → 0.71%, frequency 1.5 → 4.1.
- Act · Search · generic serum. CPA EUR 132.46 vs target EUR 40 · ROAS 0.41.
- Watch · Retargeting · 30d visitors. Strong: CPA EUR 15.31, ROAS 3.98. Scale 15-20%.
- Watch · Performance Max. CPA up 108% in the last 3 days.

Budget shift for next week
| Search · generic serum (google)  | -927.19 EUR |
| Retargeting · 30d visitors (meta)| +286.16 EUR |
| Search · brand (google)          | +641.02 EUR |
```

Full example: [`reports/weekly_review.md`](reports/weekly_review.md). The sample account in [`data/`](data/) is fictional and generated by [`adcopilot/sample.py`](adcopilot/sample.py).

## What it checks

| Check | How |
|---|---|
| **Creative fatigue** | First week vs last week per creative: CTR down by more than 25% while frequency rises more than 30% |
| **Wasted spend** | Campaigns that spent more than twice the target CPA with zero conversions |
| **Inefficient campaigns** | CPA above 1.5x target |
| **Scale candidates** | CPA under 70% of target with ROAS above target |
| **Sudden CPA spikes** | Last 3 days vs the 7 days before, up 40% or more |
| **Budget shift** | Moves up to 20% of spend away from weak campaigns, weighted toward the most efficient ones. Total budget stays the same |

Every metric is computed across platforms the same way: CTR, CPC, CPM, conversion rate, CPA, ROAS and frequency.

## Run it

```bash
git clone https://github.com/Vishwajeetkumbhar379/ad-performance-copilot
cd ad-performance-copilot
pip install -e ".[dev]"
adcopilot data/ads_export.csv --target-cpa 40 --target-roas 1.5
pytest
```

With `pip install -e ".[ai]"` and `ANTHROPIC_API_KEY` set, add `--ai` for a 4-5 sentence client summary written only from the numbers in the report.

**Input columns:** `date, platform, campaign, creative, spend, impressions, reach, clicks, conversions, revenue`. All three ad platforms export these under slightly different names; rename the headers once and save it as a template.

## Why I built it

I've run campaign reporting for brands like HUL, Philips and Lakmé, and the slow part was never the maths. It was spotting *which* number had changed and deciding what to do about it. This puts the decision rules in code, so the review takes minutes and the reasoning is the same every week.
